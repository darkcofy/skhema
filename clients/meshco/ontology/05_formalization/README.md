# Stage 5: Formalization — not yet populated

Stage 5 produces the formal, structured domain model — the deliverable
a downstream data-platform team can consume directly. For MeshCo that
would mean a canonical ontology.yaml covering all ~15 cross-domain
concepts with their properties, enums, relationships, and cardinality.

This demo stops at stage 2. Stage 5 is scaffolded but intentionally
empty.

Expected files (when populated):

- `ontology.yaml` — classes + properties + relationships, machine-readable
- `properties.yaml` — property type definitions (Money, Email, etc.)
- `enums.yaml` — enum definitions (OrderStatus, PaymentMethodType, etc.)
- `review-notes.md` — decisions made during formalisation and any
  outstanding items
